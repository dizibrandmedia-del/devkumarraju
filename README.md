# देव कुमार (राजू गुप्ता) - आधिकारिक चुनावी वेबसाइट
### स्नातक MLC प्रत्याशी — वाराणसी खण्ड (8 जनपद)

आधिकारिक डिजिटल अभियान पोर्टल: वाराणसी, जौनपुर, गाजीपुर, चंदौली, मिर्जापुर, सोनभद्र, भदोही एवं बलिया।

---

## 🌟 मुख्य विशेषताएं (Key Features)

- **आधुनिक एवं आकर्षक डिज़ाइन**: रॉयल बरगंडी एवं गोल्ड लग्जरी थीम, इंटरएक्टिव 3D कार्ड टिल्ट, और स्मूथ स्क्रॉल एनिमेशन।
- **डुअल कंपेनियन कार्ड्स स्टेज**: प्रत्याशी का भव्य पोर्ट्रेट कार्ड और जीवंत वोटिंग पिलर कार्ड।
- **16 प्रमुख संकल्प एवं वर्गवार दृष्टिकोण**: शिक्षक, छात्र/युवा, अधिवक्ता, व्यापारी एवं जनहित के मुद्दे।
- **8 जनपद निर्वाचन क्षेत्र गाइड**: सभी 8 जनपदों का विस्तृत विवरण, इतिहास एवं विकास रोडमैप।
- **1-क्लिक vCard एवं डिजिटल संपर्क**: मोबाइल फोनबुक में संपर्क सहेजने हेतु vCard (`.vcf`) डाउनलोड और सीधे व्हाट्सएप जनसंवाद।
- **100% प्रामाणिक फ़ोटो गैलरी**: ग्राउंड जनसंपर्क, विधिक संवाद, सम्मान समारोह एवं सामाजिक कार्यक्रमों की वास्तविक तस्वीरें।
- **100% रिस्पॉन्सिव एवं मोबाइल-फ्रेंडली**: डेस्कटॉप, टैबलेट और मोबाइल सभी स्क्रीनों पर सुपर-फ़ास्ट लोडिंग।

## 🚀 स्थानीय स्तर पर चलाएं (Run Locally)

किसी भी स्टैटिक वेब सर्वर अथवा Node.js द्वारा आसानी से रन करें:

```bash
# Python द्वारा
python -m http.server 3000

# या Node.js http-server द्वारा
npx http-server -p 3000
```

ब्राउज़र में खोलें: `http://localhost:3000/`
